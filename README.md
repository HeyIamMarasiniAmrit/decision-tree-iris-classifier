# Decision Tree Classifier on Iris Dataset

A simple, clean, and well-documented implementation of a **Decision Tree Classifier** using scikit-learn on the famous Iris dataset.

## Results
- **Accuracy**: 93.33%
- Stratified train-test split (80/20)
- Gini impurity criterion
- Full tree visualization included

## Features
- Clear step-by-step code
- StandardScaler applied (optional for trees)
- Confusion matrix + Classification report
- Beautiful tree plot using `plot_tree`
